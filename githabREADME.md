# GO HUB 2.0

Rozbudowany fanowski portal Pokémon GO.

## Funkcje
- automatyczne pobieranie danych z PokéAPI
- 1025+ Pokémonów w wyszukiwarce
- filtrowanie po typach
- grafiki Pokémonów
- ulubione zapisane w `localStorage`
- szczegóły/statystyki po kliknięciu
- Raidy, PvP, narzędzia i poradniki
- dark/light mode
- mobile responsive
- gotowe pod GitHub Pages

PokéAPI udostępnia publiczne endpointy REST bez wymagania autoryzacji; przed publikacją zapoznaj się z ich zasadami fair use. Dane Pokémonów są pobierane dopiero w przeglądarce. 

## GitHub Pages
1. Utwórz repozytorium.
2. Wgraj `index.html`, `style.css`, `script.js`.
3. GitHub → Settings → Pages.
4. Source: **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Save.

## Uwaga
To fanowski projekt. Nie jest oficjalnie powiązany z Pokémon GO, Niantic ani The Pokémon Company.
